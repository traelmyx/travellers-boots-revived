# Traveller's Boots Revived

Port of [Traveller's Boots: Reloaded](https://github.com/DenisMasterHerobrine/TravellersBootsReloaded) by DenisMasterHerobrine to Minecraft 1.21.1 (NeoForge and Fabric).

Five pairs of boots, MK1 to MK5. Each one makes you faster, the top two also make you jump higher, and from MK2 up you step up full blocks without jumping (hold sneak to turn that off).

The item ids and the config file (`config/travellersbootsreloaded.properties`) are the same as the original. Architectury API is no longer needed.

## Building

```
./gradlew buildAll       # all versions
./gradlew gameTestAll    # runs the game tests
```
